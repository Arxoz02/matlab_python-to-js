# matlab_python-to-js
 Adding some MATLAB and Python Libs features to JavaScript

Actual features:
## linspace(start,end,n)
- Makes an array from 'start' to 'end' of 'n' elements
- default: n=1000
## shape(matrix), size(matrix
- Gets the shape/size of a matrix
## meshgrid(x,y)
- Makes a mesh with 'x' and 'y' values
